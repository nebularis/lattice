# Validation Pack: SVA-S2b, the first instance of a class names its contracts

**Unit:** [`studio-visual-authoring`](../status/studio-visual-authoring.md), slice SVA-S2b, built on 2026-11-23 in autonomous mode, after the maintainer decided that this unit fixes the surface compiler's invalidation.

## Invariant

A contract that keeps rows records an instance-graph entry in its read set for its carrier class whether or not the source holds an instance, the empty graph's digest where it holds none. So the first instance of a class, and the last one going, each change the entry and name the contract. Every digest of a class with instances is as it was.

## What changed

- `tools/surface/src/surface/compile.py` records the entry for every contract that keeps rows. `compare_read_set` and `instance_graph_query` were already right for it.
- The run worker's `SurfaceStep` names a contract touched whenever its read-set graph differs before and after.
- The studio's writer reads no read set, so nothing there changed.
- The surface step fixture regenerated by its test: the sample that adds the first drawdown now names `drawdown-sector`.
- The contract's paragraph on which contracts an edit touches says the rule.
