## Invariant

The ledger kernel is stated once in its decided form, no definition of it reads a key's own order, the theory that states it type-checks, and each law it must keep or gain holds on every generated case the model draws. No law is proved, and the kernel that is proved today is untouched.

```bash
mise exec -- python spikes/ledger-target-kernel/model.py
```

A pass is 16 lines of results and exit 0, with no `AssertionError`. The theory is checked apart, since it needs Isabelle2025-2.

```bash
mise exec -- isabelle build -d spikes/ledger-target-kernel Ledger_Target
```

A pass is `Finished Ledger_Target`.

## Deliberate non-coverage

No law is proved, which is LG-9's and LG-20's. The cases are small, up to six requests, four ranks, three purposes and seven accounts. The model is a transliteration by hand of the theory, checked against it only through the six examples. `shares_ok` and `attributed` are not restated. The README's block and `tools/proofs/ledger/` are not changed.
