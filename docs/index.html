LATTICE

A domain-neutral semantic framework for representing governing instruments: contracts, protocols, agreements, obligations, eligibility conditions, and lifecycle behaviours.

Map

LATTICE sits between source material and executable reasoning, giving mapped concepts a precise semantic target.

Constrain

OWL, SHACL, and SKOS modules define the shape of valid governing artefacts without binding the model to one industry.

Operate

Behaviour, eligibility, party, and instrument layers provide the substrate for obligations, states, transitions, and decisions.

Seven layers, one substrate.

Each layer is independently specified and designed to compose with the others. The result is a reusable semantic foundation for governed systems, not a one-off domain ontology.

This site is currently a stub. More generated references, examples, and implementation notes will appear here as the project evolves.

Party Actors, roles, participation, and obligation direction.

Instrument Applied ontology for governing documents.
