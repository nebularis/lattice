Ontology Releases

Each version of each LATTICE ontology document is released by a git tag. Its content, and its layer's shapes and projections, can be fetched at that tag.

Generated by tools/ontology_releases.py. Rows are added, never edited. See the ontology versioning policy.

Version IRIs do not dereference yet. Until they do, a released version is fetched from GitHub at its tag, named after the release and its version (foundation-v0.3.0), following the ontology versioning policy. A layer’s shapes and projections are released on their own, versioned by the .version file in their directory, and have no version IRI.

Click a file to download it under the name shown. Opening it in a new tab shows the raw content at the tag.
