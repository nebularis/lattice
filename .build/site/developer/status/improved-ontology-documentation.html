Current position

The plan was rewritten on 2026-10-16 after two days of design discussion. It now covers three things: one README layout whose normative sections compile to Turtle and SHACL from a markdown grammar, the repository catalogue with each module’s entry in its README, and a sources discipline for user-facing documents built on published ADRs. Decisions OD-D1 to OD-D24 and the answers to RC-Q1 to RC-Q8 are in the plan. No code or ontology file has changed.

Known inconsistency on this branch (OD-D43). Migrated layers’ documents change without new version IRIs, so check:ontology-versioning reports unbumped changes, and importers stay pinned to the old versions. This is deliberate. The release slice OD-REL resolves it once, before the merge into main.
