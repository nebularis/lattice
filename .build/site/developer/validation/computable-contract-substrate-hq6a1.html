Invariant

Absence decides an outcome only under a declared closure, named by the binding that relies on it, which states on whose authority. Without one, a set reading decides only what a record proves: elg:SomeValue Permitted, elg:EveryValue Denied. Under a closure in force, some value is Denied when every value is Denied and every value Permitted when every value is Permitted, the empty case included (L15 as restated). A closure is in force from its source’s effective time and licenses the records as they stood at the deciding record’s recording time (L17). A closure never changes a single-value reading. Nothing here touches Persistence or a period of time.

Deviations from the plan:

  • All 13 proof claims re-digested, not three. A claim’s digest covers every definition in the session (E1.4), so changing some_value and every_value changes every claim’s digest. Each was re-proved before its digest was refreshed. TL2, TL3a and TL3b are restated too, since the readings take the closure. AQ’s description now reads 30 lemmas.
  • The reference test count fell from 66 to 58. The 15 adequacy tests became two table-driven tests over the 30 rows, and three closure tests and two TL4 tests were added.
  • No coupling with the differential tests. They read candidates directly with a single-value reading, so the reference’s new set readings could not disagree with the compilers there.

What to check first: §5.6 and L15’s new wording in the README, then Eligibility.thy’s two definitions and TL1 statements, then the five examples’ tables against test_closures.py.
