  • Deviations from the plan:
    1. examples/well-formed.ttl (AIR-2.1’s small, self-contained 6-concept fixture) re-declared N, T, N.MET, N.MET.TC, N.MET.TC.SRG and N.MET.TC.HUR with its own skos:prefLabel/ skos:definition text. Now that AIR-2.3 declares these for real in peril-vocab.ttl, the fixture’s own re-declarations became a second, distinct value for the same property, breaking LabelAndDefinitionShape’s “exactly one” rule. Fixed by removing the fixture’s re-declarations entirely (it now has no triples of its own beyond a header comment): the real vocabulary already supplies the hierarchy fragment the fixture existed to exercise. The fixture’s placeholder threshold for N.MET.TC.HUR is also gone, since tools/test_peril_vocabulary.py’s and tools/test_peril_intensity.py’s _fixture() helpers now both load vocab/peril-intensity.ttl (AIR-2.6), which carries the real prl:definingThreshold for every threshold-defined concept. This matches the lanes rule’s own reasoning for building AIR-2.6 before AIR-2.3 (“the thresholds must exist when AIR-2.3 assigns that basis”).
    2. For the same reason, test_air22_04_vocabulary_alone_has_no_results (AIR-2.2) started failing: vocab/peril-vocab.ttl alone now contains seven threshold-basis cause concepts whose prl:definingThreshold lives in the separate peril-intensity.ttl document by design (ADR-A120 addendum). Fixed by loading both documents together for this one test; “vocabulary alone” now means both vocabulary documents, not peril-vocab.ttl in isolation.
    3. AIR23-08’s “no definition contains cover/covered/exclude/insured/policy” needs a word- boundary match, not substring containment: four existing, correct definitions (Inundation’s “water covering land”, CancellationCosts’s “irrecoverable cost”, and this slice’s own N.HYD.FLD “water covering land” and E.LAT “not discoverable”) false-positived on a plain substring check. Fixed with a \bword\b regular expression.
    4. Performance, not a defect: tools/test_peril_vocabulary.py’s SHACL-heavy tests slowed noticeably once the cause scheme held 176 real concepts (the file’s full run moved from a few seconds to roughly 15 minutes). Logged in repo memory as an expected, worsening cost for AIR-2.4 (287 concepts), not something this slice’s scope includes fixing.
