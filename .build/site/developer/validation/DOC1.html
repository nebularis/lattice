Validation Pack: DOC1, published decisions

Unit: improved-ontology-documentation, slice DOC1 (plan). Implements: ADR-A127 decisions 1 to 4, and decision 5’s hiding of unpublished ADRs, with OD-D37 to OD-D39 and OD-D47 to OD-D50. Built autonomously, at the maintainer’s request of 2026-10-19. The publication pass over twelve ADRs was done by a second developer working in the same checkout, and reviewed here. The decisions taken alone are listed below.

Invariant

Every user-facing document cites only published decisions and refers to no working document. A migrated README and the files it generates fail the check on either. A README not yet migrated is reported. A published ADR may cite an accepted one, by an absolute link, and never a proposed one. Every published ADR has a Provenance section, a Described in line and published: true front matter, and is on the generated list. The site shows published ADRs only.

What changed

  • tools/published_decisions.py. Reads every ADR’s status, Described in line and front matter, writes docs/architecture/published-architecture-decisions.md, and checks the list is current and every published ADR meets ADR-A127 decision 2.
  • tools/sources_check.py. Reads every line of every user-facing document: the module READMEs the catalogue lists, the files each generates, published ADRs outside Provenance, and the list.
  • mise.toml. build:published-decisions, and check:published-decisions, which runs both checks and the tests and is part of mise run check and the full sweep.
  • docs/_config.yml. A defaults entry gives every page under architecture/decisions published: false.
  • The publication pass (OD-D38, OD-D50). The twelve ADRs Eligibility’s README cites, now that ELC’s release note cites ADR-A03 and ADR-A05 too: @@ADRS@@. Each gained front matter, the published status line, a Described in line and a Provenance section holding its references to working documents. Links to unpublished ADRs are absolute. The decisions index marks them Published.
  • ADR-A127 gains an addendum for OD-D47 and OD-D49.

Decisions taken alone, for the maintainer

  1. An absolute link to an unpublished ADR points at main, not at a release tag. OD-D47 said “the release tag”, but an ADR belongs to no ontology document’s release, and a tag would point at the decision as it stood before it was published.
  2. A working document is recognised by its path, developer/sketches/, plans/, status/, reviews/, validation/, notes/ or developer/INDEX.md. Question and slice IDs, such as “HQ6a-Q1”, are not detected. The publication pass removed them by reading each ADR.
  3. A published-then-superseded ADR reads Superseded by ADR-An. Published YYYY-MM-DD. and stays on the list, marked. No ADR is in that state yet.
  4. A README not yet migrated is reported, never failed, for working documents as well as citations, since 385 such reports exist today. They become failures as each layer migrates.
  5. A citation of an ADR with no file is reported, never failed. Three exist today in ADRs that are not published (A101, A108 and A109).
  6. The list’s Described in links are rewritten relative to the list’s own directory.
