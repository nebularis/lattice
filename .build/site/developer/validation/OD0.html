Drafting choices, for the maintainer

  1. Published is a fourth status after Accepted, set by the maintainer with a date (ADR-A127 decision 1).
  2. The list of published decisions is generated from the ADRs’ Status lines and checked (ADR-A127 decision 3). Our discussion did not settle whether it is generated or kept by hand.
  3. Accepted ADRs leave the site until published. Until a README is migrated and the decisions it cites are published, the sources check reports a citation of an Accepted ADR rather than failing (ADR-A127 consequences). Without this, every README would fail the check on the day it lands.
  4. The AGENTS.md rule tells agents to cite Accepted ADRs until decisions are published. That is the same transition, stated for agents.
  5. ADR-A01’s convention note (the ontology header in a README’s first turtle-spec block) gains an addendum when ADR-A126 is accepted, since section 2 then holds the header (ADR-A126 consequences).
  6. A change to the substrate’s import order in the catalogue needs an amendment to ADR-A01 (ADR-A121 decision 2). This keeps ADR-A01 as the decision while the catalogue becomes where tools read it (RC-Q3 option C).
