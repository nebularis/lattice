Invariant

An unchanged member of an exposure set is shared by every version of the set it holds for, by identity, and is never copied to make a new version. No property of the module says a member belongs to one set, one location or one assessment. A reasoner therefore never merges two schedule versions, two location versions or two assessments that list one node.

Deliberate non-coverage
