## What this means in practice

Building a product, service, or internal tool that *implements* what these documents describe — an Instrument extraction pipeline, a Behavioural overlay engine, a downstream ontology layered on Foundation or Party — is not covered by ShareAlike at all. That is use, not adaptation of the document. ShareAlike engages only if you take the specification text itself, modify it, and redistribute the modified text; at that point, your modified version carries the same licence forward.

This mirrors the MPL boundary in `/LICENSE`: the thing you build using this material stays yours on whatever terms you choose; changes to the material itself circulate back under the same terms it came with.
