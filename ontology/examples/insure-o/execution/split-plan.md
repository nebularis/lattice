# Execution split plan

This execution profile is intentionally illustrative. It demonstrates a possible shadow-compilation approach that materialises local hierarchy closures and a small allowance profile without making compilation a semantic requirement.

## Components

- A generated marker profile for hierarchical dimensions such as peril
- A local closure derived from `skos:broader` for the bound scheme values
- A sequential allowance profile over a declared capacity resource

## Operational intent

The shadow profile is a runtime accelerator only. The source of truth remains the LATTICE substrate declarations and SHACL rules.
