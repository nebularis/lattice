# Behaviour execution invalidation policy

Behaviour derived execution artefacts are invalidated when any referenced declaration changes: state space, state, transition, trigger, guard, effect, allowance definition, or any imported Eligibility, Instrument, Party, or Quantification artefact they depend on.

At Gate 3 this policy is documented only. No execution compiler or cache manager is built yet.
