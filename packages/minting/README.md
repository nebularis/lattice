# Identity Minting Libraries

Standalone libraries that mint IRIs from a LATTICE minting recipe, as the [identity minting specification](../../docs/architecture/identity-minting-specification.md) defines ([ADR-A84](../../docs/architecture/decisions/ADR-A84-standalone-minting-libraries.md)). Neither depends on any other LATTICE code, and neither needs the persistence compiler at run time: give it a recipe file and it mints.

You do not need these libraries to mint LATTICE identifiers. The specification, the schemas and the vectors in [`contracts/identity/`](../../contracts/identity/README.md) are enough to write your own minter and prove it conformant.

| Directory | What it is |
|---|---|
| [`python/`](python/README.md) | `lattice-minting` for Python 3.14 or later. Standard library only |
| `java/` | The Java 25 library (slice M3 of the [`identity-minting`](../../docs/developer/plans/identity-minting.md) unit). Today it holds only the shared Unicode tables |
| `testdata/` | Recipes compiled from [`identity-minting-anchors.ttl`](../../ontology/persistence/examples/identity-minting-anchors.ttl) and the conformance vectors generated from them. Regenerated by `mise run build:minting-vectors`, never edited by hand |
| `tools/generate_ucd_tables.py` | Writes the pinned Unicode 16.0.0 tables into both libraries from the Unicode Character Database. `--check` fails if a committed table differs |

## Unicode data

Both libraries read the same generated tables, byte for byte, so that neither depends on its runtime's case mapping or whitespace rules. The tables derive from the Unicode Character Database 16.0.0, used under the [Unicode License v3](https://www.unicode.org/license.txt). `SOURCES.txt` beside the tables records each source file's URL and SHA-256.

## Checks

```bash
mise run check:minting-anchors   # the anchor vectors, recomputed with openssl
mise run check:minting-python    # the Python library against the anchors and testdata
mise run check:minting-tables    # the tables against the UCD
mise run build:minting-vectors   # regenerate testdata after a deliberate behaviour change
```
